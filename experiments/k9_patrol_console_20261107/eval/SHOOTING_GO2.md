# Go2 누운 자세 촬영 (11/05 할 일 2번)

Go2 카메라로 찍은 서 있음·앉아 있음 장면은 `data/media` 에 이미 있어 이번에는 **누운 자세만** 찍는다.
(11/7 기준 실제 Go2 프레임: 서 있음 23장, 앉아 있음 73장, 누움 0장)

## 준비
- K9 콘솔 실행 → Go2 연결 → 설정에서 비전 모델 `자세 추정 · Nano`, 사람 등장 시 전후 영상 저장 켬
- 한 번에 한 사람만 화면에. 바닥에 매트 깔기
- 로봇은 서 있는 기본 자세(카메라 바닥에서 약 30cm), 움직이지 않은 상태에서 촬영 (흔들림 방지)

## 촬영 목록 (6장, 순서대로)
각 장면을 **5초 이상 유지**하고, 화면에 사람이 잡힌 상태에서 `캡처` 를 누른다. 설정의 제목 칸에 아래 제목을 먼저 적어 둔다.

| 순서 | 제목 | 장면 | 확인하려는 것 |
|---|---|---|---|
| 1 | lie_side_2m | 옆으로 보이게 누움 (몸이 화면 가로), 2m | 기본 누움 판정 |
| 2 | lie_side_4m | 같은 자세, 4m | 거리 영향 |
| 3 | lie_headon_1.5m | 머리가 로봇 쪽, 1.5m | 엉덩이 관절이 가려지는지 (사진 실험 실패 유형 B) |
| 4 | lie_headon_3m | 머리가 로봇 쪽, 3m | 거리 늘면 달라지는지 |
| 5 | lie_feet_2m | 발이 로봇 쪽, 2m | headon 반대 방향 |
| 6 | sit_floor_2m | 바닥에 다리 뻗고 앉음, 2m | 누움으로 잘못 나오는지 (오탐 확인) |

시간이 부족하면 6 → 5 → 2 순서로 생략.

## 찍은 뒤
```bash
cd k9_patrol_console
python eval/posture_eval.py          # eval/out/img 에 관절 그림, eval/out/summary.md 에 결과
```
`eval/out/img` 를 보고 새 프레임의 실제 자세를 `eval/labels.csv` 에 추가한 뒤 다시 실행한다.
판정 기준값은 사진에 맞춰 바꾸지 않는다. 바꾸면 바꾼 이유와 전후 결과를 둘 다 남긴다.
