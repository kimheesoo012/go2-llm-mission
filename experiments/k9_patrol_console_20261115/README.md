## 새 기준

관절 각도 대신 관절의 세로 위치 비율을 씁니다. 사람이 어느 방향을 보더라도 유지되는 특징입니다.

| 자세 | 보는 특징 |
|---|---|
| 서 있음 | 골반이 발목보다 충분히 높고, 무릎이 그 중간쯤 (한쪽 다리만 맞아도 인정) |
| 앉음 (의자형) | 몸통이 세워져 있고 무릎이 골반 높이 근처 |
| 앉음 (바닥형) | 몸통이 세워져 있고 발목이 골반 높이 근처 |
| 누움 (옆모습) | 몸통이 가로이고, 몸 전체가 가로로 길거나 다리가 골반 높이 근처 |
| 누움 (카메라 방향) | 몸통이 어깨 너비보다 짧게 찍히고 다리도 낮음 |
| 누움 (머리가 앞) | 어깨가 골반보다 아래에 찍히고 다리가 그 뒤로 이어짐 |
| 누움 (비스듬히) | 몸통이 바닥에서 일어선 각도(추정)가 45° 이하이고 다리도 낮음 |
| 판단 불가 | 위 어디에도 안 들거나, 다리 값이 서 있음과 앉음의 중간 |

- 누움을 가장 먼저 검사하고, 누움 조건을 앉음·서 있음보다 넓게 잡았습니다. 누움을 놓치는 것이 가장 큰 손해이기 때문입니다.
- 몸통 각도는 사람이 비스듬히 있어도 추정되도록 어깨 너비를 함께 씁니다(몸통 길이 ≈ 어깨 너비 × 1.4 가정).
- 양쪽 관절을 모두 요구하지 않고 보이는 쪽으로 계산합니다.
- 골반 없이 다리만 보이면 정강이가 세로로 길 때 서 있음으로 보고 이유에 "약한 근거"라고 적습니다. `shin_only=False`로 끌 수 있습니다.
- 판단 불가 이유를 "너무 가깝거나 일부만 보임"과 "조건 불충족"으로 나눴습니다.

1. **11/14 영상 클립 전체** (`eval/result_20261114_clip_frames.txt`): 저장된 클립 55개에서 0.5초마다 프레임을 뽑아 콘솔과 같은 설정으로 포즈 모델을 돌렸습니다. 화면에서 실시간으로 보던 상황에 가장 가까운 자료입니다.

   | 사람 검출 294건 | 촬영 때 규칙 | 새 규칙 |
   |---|---|---|
   | 서 있음 | 102 | 137 |
   | 앉음 | 12 | 38 |
   | 누움 | 4 | 9 |
   | 너무 가까움 (표시만 분리) | - | 106 (36%) |

   - 이 106건을 자세로 바꿔 보려는 시도는 효과가 없었습니다: 관절 신뢰도 기준을 0.45 → 0.2로 낮춰도 6건, 같은 클립의 직전 자세를 이어받아도 5건.

   - 이 106건을 빼면 188건 중 판단된 것이 118건(63%) → 184건(98%)입니다.
   - 판단 불가에서 자세로 바뀐 66건은 사진으로 모두 확인했고 틀린 것은 없었습니다. 기존에 판단되던 118건은 결과가 그대로입니다.

## 한계

- 11/14 자료를 보면서 기준값을 정했으므로 새 영상에서 같은 결과가 나온다는 보장은 없습니다. 96프레임 세트만 기준을 정할 때 보지 않은 자료입니다.
- 실제 자료에 누움은 옆모습·웅크림·머리가 카메라 쪽 몇 장뿐이고, 발이 카메라 쪽인 누움은 없습니다.
- 상체가 잘리고 다리만 보이는 앉음은 옆모습만 인정합니다(정면은 판단 불가).
- 등 뒤에서 본 앉음처럼 다리가 전혀 안 보이면 판단 불가입니다.
- 선 채로 카메라 쪽으로 비스듬히 허리를 숙이면 가까운 거리에서 서 있음으로, 무릎 꿇고 엎드린 자세는 누움으로 나옵니다.
- 한 장으로 판단하므로 관절이 흔들리면 결과가 바뀝니다. 최근 몇 장의 다수결은 넣지 않았습니다.
- 사람이 로봇 바로 옆에 있으면 여전히 판단 불가입니다(이유만 따로 표시).
