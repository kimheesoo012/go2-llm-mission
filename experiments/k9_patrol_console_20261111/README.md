# K9 콘솔 도움 요청 판정 · 누운 자세 지속 · 관제자 알림 · 순찰 보고서 (2026-11-11)

팀 순찰 관제 프로그램(K9 PATROL 콘솔)에 다음 기능을 연결한 작업입니다.

1. **도움 요청 판정**: STT 원문에 "도움 요청 / 도움 요청 의심" 단계를 붙입니다. 11/05에 "살려주세요"가 "사랑해주세요"(4회)로 저장된 기록이 의심으로 표시됩니다.
2. **누운 자세 지속**: 프레임 한 장이 아니라 15초 이상 이어질 때만 기록과 알림을 냅니다.
3. **관제자 알림**: 긴급 확인 / 확인 필요 / 참고 단계로 화면 상단에 표시하고 경고음을 냅니다.
4. **중요 장면 선정 규칙 우선**: 규칙이 고른 기록은 LLM이 빼지 못하고, LLM 연결이 끊겨도 표시됩니다.
5. **순찰 보고서**: 건수와 확인이 필요한 기록은 규칙으로 계산하고, 총평만 LLM이 씁니다.

콘솔 전체 코드는 팀 저장소에 있으며, 이 폴더에는 **제가 작성한 변경 사항(패치)과 결과 문서**만 담았습니다. 녹음·영상·기록 DB 같은 원본 데이터는 포함하지 않았습니다.

## 사용 방법

팀 저장소의 K9 콘솔 폴더 상위에서:

```bash
git am k9-help-request-alerts.patch
cd k9_patrol_console
python -m pytest -q                          # 테스트
python eval/selection_eval.py --mode llm     # 선정 시나리오 LLM 채점 (Ollama 실행 필요)
python app.py                                # 콘솔 실행
```
