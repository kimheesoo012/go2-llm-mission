- 프롬프트 없이 돌린 결과는 저장된 원문과 같다 (재현됨).
- 프롬프트를 주면 "사랑해주세요", "눈 와주세요"가 사라지고 도움 요청 표현으로 인식된다.
- 그러나 발화 횟수가 줄었다 (4→3, 4→2, 5→4). 프롬프트에 있는 표현 쪽으로 결과가 끌려간다는 뜻이다.
- **세 파일 모두 실제로 도움 요청을 말한 녹음이다.** 일상 대화나 소음만 있는 녹음에서 프롬프트가 없는 도움 요청을 만들어내는지는 확인하지 못했다. 이 확인 전에는 콘솔에 적용하지 않는다.
